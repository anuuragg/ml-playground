# CNN Food Classification

![Project Image](https://d2908q01vomqb2.cloudfront.net/cb4e5208b4cd87268b208e49452ed6e89a68e0b8/2017/11/15/SiliconValley.jpg)

A simple CNN-based food image classifier built with TensorFlow/Keras.

Uses the **Food-101 dataset** through TensorFlow Datasets (TFDS), along with image preprocessing, dropout, and L2 regularization.

## Run the Streamlit App

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch the app:

```bash
streamlit run app.py
